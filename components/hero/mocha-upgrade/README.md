# Mocha component upgrade adapter

The visual primitives in this directory are adapted from
`tubingqing-oss/Mocha-Component-Upgrade-Testing` at commit
`1d40f28ee8874009c98936da550019d24c93d9f9`.

Only the presentation contract is reused. The marketing site keeps its existing
local task configuration, compressed playback state, translations and Mol* 3D
viewer. The source repository's HEWL data, global styles and external URLs are
not included. No runtime API, WebSocket, storage or telemetry client is present.

No license file was present in the inspected source repository. This provenance
record is retained pending confirmation from the source owner.
