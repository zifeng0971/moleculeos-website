<strong>Top Navigation Bar:</strong> Houses project switching, sharing options, system notifications, and account settings.

<strong>Left Node Tree:</strong>

-   <strong>Protein Nodes:</strong> Displays all protein structures loaded in the active project. Click any node to select and switch focus.
-   <strong>Amino Acid Groups:</strong> Displays user-defined residue annotations and selection groups.

<strong>Central Display Area:</strong> Shows sequence attributes (top panel) and 3D molecular structures (bottom panel) for the currently selected protein.

<strong>Basic Toolbar:</strong> Contains standard viewing operations, including Zoom In/Out, Center/Reset, Representation controls, Distance measurement, Overlay toggling, and Interaction views.

<strong>Floating Toolbar:</strong> Houses core execution modules, including Superimposition, Model Execution, Homology Search, and the Mocha AI Assistant.
