During protein design and optimization, homologous proteins provide valuable reference data, such as conserved sites and functional characteristics. MOS connects directly to external databases. Once you input a target sequence or chain and set filtering parameters, it returns a ranked list of homologs based on similarity.

<h3 id="4-homologous-protein-search-seqsimsearch-overview-metric-definitions"><a id="heading_63"></a><strong>Metric Definitions</strong></h3>

-   <strong>ID:</strong> Identifier of the matched sequence.
-   <strong>Hit:</strong> Subject sequence in the database (specified under Reference).
-   <strong>Score:</strong> Raw alignment score calculated from matches, mismatches, and gap penalties; used to compare results within the same search.
-   <strong>E-value:</strong> Expect value representing the number of chance alignments expected in the database (e.g., an E-value of 1 indicates a likely random match, whereas 1e-50 indicates high confidence).
-   <strong>Bit score:</strong> Normalized score derived from the raw score; allows comparison across different searches.
-   <strong>% ID:</strong> Percentage of identical amino acids across the aligned region, including gaps.
-   <strong>Reference:</strong> Source database containing the hit sequence.
