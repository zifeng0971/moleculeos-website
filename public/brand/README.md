# Approved dark-background brand assets

These PNG assets preserve the original logo gradient and white negative space:

- `logo-mark-dark-256.png` — 256px source, rendered at 32px in navigation and 28px in the footer
- `favicon-32.png`, `favicon-64.png` — browser icons
- `apple-touch-icon.png` — Apple home-screen icon

Do not filter, recolor, blend, fade, or alter these assets on hover. They are for dark backgrounds only; light backgrounds require separate approved resources.
