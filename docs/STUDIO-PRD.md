# MOS Agent v2 — 产品定义

> 配套原型：`/studio`。上一版概念见 `STUDIO-CONCEPT.md`。本文件是 v2 的产品决策与验收标准。

## 1. 我们在解决什么

**北极星指标：从“一个研究目标”到“一份站得住的下一轮实验候选清单”所需的时间。**

今天在 MOS 里，这条路要经过：懂模型缩写 → 填表发任务 → 等通知 → 下载 CSV → 在 Excel 里交叉比对 → 回到结构里找位点。每一步都在丢上下文。

## 2. 目标用户与场景

| 角色 | 典型问题 | 他们在乎什么 |
| --- | --- | --- |
| 抗体 / 蛋白工程师（主用户） | “G6 的亲和力还能怎么提？” | 结论可信、能追到证据；不想学模型名 |
| 计算生物学家 | “参数是什么？能复现吗？” | 参数、版本、可复制、可下载原始数据 |
| PI / 项目负责人 | “这轮推荐哪几个、为什么？” | 一眼看懂的摘要和风险；能转发 |

## 3. 产品原则

1. **对话是入口，不是牢笼。** 一句话就能开始；但 agent 做的每件事（计划、模型调用、文件）都可展开、可复制、可单独打开。
2. **先有证据，再有结论。** 回答里的每个残基都能点开定位；每次模型调用都带来源；每个推荐都标风险。
3. **结构一进来，就先读懂它。** MMetrics 在任何结构进入会话时自动运行，是这个蛋白的“档案”。用户不用请求，agent 也会引用它。
4. **花钱前先说清楚。** 算力消耗在运行前显示，用户掌握运行模式。
5. **产出能交接。** 候选清单、结构、报告都是可下载、可转发的文件。

## 4. MMetrics 的定位（v2 重点）

MMetrics 不再是右侧面板里的一个 Tab，而是**每个结构的档案（Structure dossier）**：

- **自动触发**：结构进入会话（预测、上传、PDB ID）→ 自动运行 MMetrics，以工具调用显示在对话中，无需确认（不消耗积分）。
- **对话内摘要卡**：类型与置信度、链组成、CDR、界面互作数、同源最高相似度、可开发性风险数；一键“打开完整档案”。
- **工作台停靠面板**：结构标签页下方的停靠区在“序列 / MMetrics”之间切换。档案与 3D 永远同屏，点任何条目都在 3D 中高亮。
- **档案内容**（与现有 MMetrics 输出对齐）：
  - 概述：类型 + 置信度、名称、来源、功能、判断依据、各链组成
  - 同源：前 5 条，晶体结构标记、序列一致性、外部链接
  - 注释：CDR（IMGT / Kabat / Chothia / AHo 编号切换）、表位、重 / 轻链，可多选、可清除
  - 互作网络：2D 网络图（抗体侧 ↔ 抗原侧，线型 / 颜色区分作用类型，标注距离）与表格两种视图，按类型过滤
  - 可开发性风险：CDR 中的化学不稳定基序（脱酰胺 NG、异构化 DG、糖基化 N-x-S/T、游离 Cys、氧化 Met/Trp）
  - 突变打分：MutXseq / MutXstruct / MutXevo 三个文件，可预览、在工作台打开为表格、下载
- **Agent 引用档案**：回答中写明“依据 MMetrics 档案”，残基可点击。

## 5. 关键旅程（验收用）

1. **新用户首屏 30 秒内发起第一次计算**：点示例 → 发送 → 看到链识别和计划 → 确认算力 → 运行。
2. **结构到洞察零点击**：预测完成后，MMetrics 自动运行，对话里出现摘要卡，工作台自动停靠档案。
3. **证据追溯**：点击回答中的任一残基，3D 聚焦、序列条高亮、档案中对应条目可见。
4. **从扫描到交接**：亲和力扫描 → 稳定性 → 候选表（带风险标记）→ 下载 CSV。
5. **可开发性把关**：候选清单中命中 MMetrics 风险基序的突变会被标出。

## 6. 视觉方向

参考一线 AI 产品（Claude、Linear、Cursor、Arc）的克制与精致：

- 中性深色为默认，支持浅色主题（投影汇报、打印场景）
- 一种品牌强调色（紫 → 粉渐变仅用于品牌与进行中状态），科学数据用专用色阶（pLDDT 蓝 / 青 / 黄 / 橙，ΔΔG 发散色阶）
- 信息密度高但呼吸感足：8px 栅格、清晰的层级、等宽字体只用于标识符和数据
- 动效只用于反馈状态变化（流式、进度、出现），尊重“减少动态效果”

## 7. 不在本轮范围

真实后端接入、账号与权限、多人实时协作、移动端完整适配。
